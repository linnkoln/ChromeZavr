## Информационная архитектура страницы

Страница состоит из вертикального стека зон (центр экрана):

| Зона | Элемент | Видимость |
|---|---|---|
| 1 | Кнопка «Начать загрузку» (`#start-btn`) | до старта загрузки |
| 2 | Прогресс-бар (`#progress-wrap`) | во время загрузки |
| 2a | Сообщение «✅ Загрузка завершена!» (`#done-msg`) | после загрузки, если игра НЕ начата |
| 2b | Кнопка «Загрузка завершена — перезагрузить» (`#reload-btn`) | после загрузки, если игра начата |
| 3 | Подсказка про пробел/мышь (`#hint`) | во время загрузки |
| 4 | Placeholder игры (`#game-placeholder`) | после пробела/клика |

Зоны 2a/2b занимают одно и то же место (взаимоисключающие). Кнопка перезагрузки всегда выше placeholder игры.

## Юзерфлоу

```
[Старт]
   │ клик «Начать загрузку»
   ▼
Кнопка исчезает ──► [Прогресс-бар 0→100%] + подсказка
   │                          │
   │            пробел / клик по пустому месту (в любой момент)
   │                          ▼
   │                 [Placeholder игры виден]
   │                          │
   ▼                          ▼
100%? ── да ──► игра начата?
                  │                │
                 нет              да
                  ▼                ▼
        [Сообщение «Завершено!»] [Кнопка «Перезагрузить»]
                  │                       │
        (точка расширения:               │
         onLoadingFinished)              ▼
                                  location.reload()
```

### Состояния (state machine)

| Состояние | loaded | gameStarted | Что видно |
|---|---|---|---|
| Idle | false | false | кнопка старта |
| Loading | false | false | прогресс-бар + подсказка |
| Loading+Game | false | true | прогресс-бар + placeholder игры |
| Done | true | false | сообщение «Завершено!» (+ будущее действие) |
| Done+Game | true | true | кнопка перезагрузки + placeholder игры |

Переходы: Space/click переводит Loading→Loading+Game и Done→Done+Game; завершение загрузки переводит Loading→Done или Loading+Game→Done+Game.

## Точки расширения (placeholders)

1. `startLoading()` — имитация загрузки, заменить на реальную (см. LOADING_PAGE.md).
2. `onLoadingFinished()` — действие/переход после загрузки, когда игра не начата.

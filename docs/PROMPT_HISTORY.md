# История промптов пользователя

Хронологический лог требований пользователя к проекту.

## Промпт 1
Мне нужна страница с кнопкой, которая начинает загрузку (загрузка длится полминуты). Когда загрузка заканчивается — сообщение на 2 секунды о том, что загрузка закончена, и страница перезагружается.

## Промпт 2
- В процессе загрузки будет отображаться игра.
- Под шкалой загрузки вывести текст: «нажмите пробел или кнопку мышки, чтобы начать игру».
- Игру пока не делать — вставить placeholder под шкалой загрузки. Игра появляется только после соответствующего действия пользователя (пробел или клик мышкой по пустой части экрана).
- Если игра началась — не перезагружать страницу автоматически; вместо шкалы вывести кнопку «загрузка завершена», перезагрузка по её нажатию.
- Ожидание загрузчика — placeholder, который потом будет заменён на действие или переход на другую страницу. Реализовать в коде, показать где, зафиксировать в документации.

## Промпт 3
Сама загрузка — тоже placeholder реальной загрузки. Реализовать это в коде так, чтобы было легко найти заменяемую часть, и добавить в документацию.

## Промпт 4
- Перенести проект на git, ввести контроль версий.
- Добавить в документацию историю промптов пользователя.
- Добавить отдельный файл изменений проекта (CHANGELOG).
- Завести документ с описанием информационной архитектуры и юзерфлоу проекта.
- Placeholder игры должен вызываться не только после окончания загрузки, но и прямо во время загрузки.
- После нажатия «Начать загрузку» кнопка должна пропадать, оставался только прогресс-бар.
- Прогресс-бар после завершения загрузки заменяется: на сообщение «загрузка завершена» (если игра не начата), либо на кнопку перезагрузки (если игра была начата). Кнопка должна быть выше placeholder игры.

# Документация: loading-page.html

Страница загрузки с мини-игрой (пока placeholder).

## Текущее поведение

1. Кнопка **«Начать загрузку»** запускает прогресс-бар на 30 секунд (`DURATION = 30000`).
2. Под шкалой появляется подсказка: «Нажмите пробел или кнопку мышки, чтобы начать игру».
3. По завершении загрузки:
   - на 2 секунды показывается сообщение «✅ Загрузка завершена!»;
   - **автоперезагрузка отключена**, если игра ещё не начата.
4. Игра запускается по **пробелу** или **клику мыши по пустой части экрана** (клики по кнопкам игнорируются).
5. При старте игры шкала загрузки скрывается, показывается placeholder игры и кнопка
   **«Загрузка завершена — перезагрузить»** — перезагрузка только по её нажатию.

## Точки расширения (что заменять на реальную реализацию)

### 1. Сама загрузка — placeholder реальной загрузки

**Где в коде:** функция `startLoading()` в `<script>` (помечена комментарием
`=== ЗАГРУЗКА — PLACEHOLDER РЕАЛЬНОЙ ЗАГРУЗКИ ===`). Сейчас она имитирует процесс
таймером на `DURATION` мс. **Заменить её тело** на реальную логику загрузки
(fetch ресурсов, загрузка ассетов игры, обращение к API и т.п.).

Контракт:
1. сообщать прогресс вызовом `setProgress(0..100)`;
2. по завершении вызвать `finishLoading()` — дальше всё (сообщение, точка расширения,
   ожидание старта игры) сработает автоматически.

### 2. Действие по завершении загрузки

**Где в коде:** функция `onLoadingFinished()` (комментарий
`=== ТОЧКА РАСШИРЕНИЯ ЗАГРУЗЧИКА (placeholder) ===`). Вызывается из
`finishLoading()` при достижении 100%. Сейчас тело пустое (TODO), в будущем —
реальное действие или переход, например:

```js
window.location.href = '/next-page.html';
```

# Файлы эпох — формат

Движок (`engine.js`) читает эпохи из глобального массива `window.ChromeZavrEpochs`.
Каждый файл эпохи — самодостаточный JS-файл в `assets/epochs/`, который
добавляет один объект в этот массив. **Порядок подключения файлов в HTML =
порядок прохождения эпох** (от настоящего в прошлое).

## Где лежат и как подключаются

```
assets/epochs/
├── 01-sapiens.js
├── 02-erectus.js
├── 03-first-mammals.js
├── 04-tiktaalik.js
└── 05-luca.js
```

В `loading-page.html` (PROD) и `index-dev.html` (DEV) файлы подключаются
**до** `engine.js`:

```html
<script src="assets/epochs/01-sapiens.js"></script>
...
<script src="engine.js"></script>
```

## Формат файла эпохи

```js
/* Эпоха N: Название. Формат — см. docs/EPOCH_FILES.md */
window.ChromeZavrEpochs = window.ChromeZavrEpochs || [];
window.ChromeZavrEpochs.push({
  id: 'unique-id',              // обяз.: уникальный идентификатор
  name: 'Название эпохи',        // обяз.: показывается СВЕРХУ экрана
  timeLabel: 'текст',           // опц.: статичная подпись времени
  yearsAgo: 375000000,          // обяз. для нелинейного счётчика времени:
                                // сколько лет назад от сейчас (число)
  heroName: 'Имя героя',        // обяз.: показывается ПОД персонажем
  enemies: ['Враг 1', ...],     // обяз.: список противников СПРАВА СНИЗУ
  palette: {                    // обяз.: цвета эпохи (ассеты пока не созданы)
    bg: '#ffffff',              //   фон
    ground: '#cccccc',          //   линия земли
    player: '#2563eb',          //   цвет героя
    enemy: '#dc2626'            //   цвет препятствий
  }
});
```

## Правила

1. Файл не должен ничего знать о других эпохах — только `push` своего объекта.
2. Имя файла: `NN-slug.js`, где `NN` — двузначный порядковый номер эпохи.
3. `yearsAgo` заполняется по сюжету (`docs/Plot/STORY_CURRENT.md` / `STORY.md`).
4. Новые ассеты (спрайты, звуки) пока не созданы; когда появятся — в объект эпохи
   добавляются поля ассетов (например `sprite: 'assets/sprites/tiktaalik.png'`),
   а движок начнёт их использовать вместо прямоугольников.
5. Если массив пуст или файлы не подключены — движок использует встроенную
   дефолтную эпоху.

## Механика смены эпох в игре

- Каждые `SCORE_PER_EPOCH` очков (сейчас 150) игрок переходит к следующей эпохе.
- При смене: очистка препятствий, вспышка «Новая эпоха: …» с подписью времени.
- Счётчик времени **нелинейный**: между эпохами интерполируется по логарифмической
  шкале между `yearsAgo` текущей и следующей эпохи и отображается как
  «лет / тыс. лет / млн лет / млрд лет назад».
- DEV: `ChromeZavrGame._dev.setEpoch(i)` — прыжок в эпоху по индексу для теста.

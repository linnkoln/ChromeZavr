# CHANGELOG

Все значимые изменения проекта. Формат основан на Keep a Changelog.

## [0.5.0] — 2026-08-21

### Added
- Геймплей: аналог динозаврика Chrome — бесконечный раннер на canvas (`engine.js`): прыжок по пробелу/клику, спавн препятствий, счётчик очков, рост скорости, экран Game Over с рестартом.
- Функции разработчика в движке: активируются только вызовом `enableDevFeatures()` (в PROD по умолчанию выключены).
- DEV-сборка `index-dev.html`: тот же файл, что PROD, + вызов `enableDevFeatures()` и чит-панель (GodMode, пропуск загрузки, рестарт, скорость 0.5–4×).
- Общий движок `engine.js` для обеих сборок.

## [0.4.1] — 2026-08-21

### Fixed
- Восстановлена автоперезагрузка, если игра не начата: сообщение «✅ Загрузка завершена!» показывается 2 секунды, затем страница перезагружается.

## [0.4.0] — 2026-08-21

### Changed
- Placeholder игры теперь можно вызвать **во время загрузки** (пробел/клик), а не только после её окончания.
- Кнопка «Начать загрузку» исчезает после нажатия — остаётся только прогресс-бар.
- Прогресс-бар по завершении загрузки заменяется:
  - сообщением «✅ Загрузка завершена!» — если игра не начата;
  - кнопкой «Загрузка завершена — перезагрузить» — если игра начата (кнопка расположена выше placeholder игры).

## [0.3.0] — 2026-08-21

### Changed
- Логика загрузки вынесена в placeholder `startLoading()` с контрактом `setProgress()` / `finishLoading()` — тело функции заменяется на реальную логику загрузки.

## [0.2.0] — 2026-08-21

### Added
- Подсказка под шкалой: «Нажмите пробел или кнопку мышки, чтобы начать игру».
- Placeholder игры (`#game-placeholder`), запускается пробелом или кликом по пустой части экрана.
- Точка расширения `onLoadingFinished()` — будущий переход/действие по завершении загрузки.

### Changed
- Автоперезагрузка отключена при начатой игре: вместо шкалы показывается кнопка перезагрузки.

## [0.1.0] — 2026-08-21

### Added
- Первая версия: кнопка → 30 с прогресс-бар → сообщение на 2 с → автоперезагрузка.

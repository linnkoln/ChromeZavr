# ChromeZavr 🦖→🧬

Браузерная игра-раннер об эволюции: от **Homo sapiens** до **LUCA** — начала всей жизни.
Аналог динозаврика из Google Chrome, где каждый пройденный отрезок игры отбрасывает
вас вглубь времени на миллионы (и миллиарды) лет.

![версия](https://img.shields.io/badge/версия-0.6.0-blue)

## Как запустить

Проект — чистые HTML/JS без сборки и зависимостей. Нужен любой современный браузер.

### Вариант 1: просто открыть файл (быстрее всего)

1. Скачайте репозиторий (Code → Download ZIP, либо `git clone`):
   ```bash
   git clone https://github.com/linnkoln/ChromeZavr.git
   cd ChromeZavr
   ```
2. Откройте двойным кликом:
   - **`loading-page.html`** — обычная версия игры;
   - **`index-dev.html`** — версия с чит-панелью разработчика.

> Файлы самодостаточны и работают через `file://` — локальный сервер не требуется.

### Вариант 2: локальный сервер (опционально)

```bash
# Python
python -m http.server 8000
# или Node
npx serve .
```
Затем откройте http://localhost:8000/loading-page.html

### Вариант 3: играть онлайн (GitHub Pages)

Если Pages включён: https://linnkoln.github.io/ChromeZavr/loading-page.html

## Как играть

1. Нажмите **«Начать загрузку»** — пойдёт прогресс-бар (30 секунд).
2. В любой момент (даже во время загрузки) нажмите **пробел** или **кликните по экрану** — начнётся игра.
3. **Прыжок** — пробел или клик. Перепрыгивайте препятствия, набирайте очки.
4. Каждые **150 очков** — переход в предыдущую эпоху: меняется герой, палитра, враги,
   а счётчик времени нелинейно уносится в прошлое:
   **Homo sapiens → Homo erectus → первые млекопитающие → Tiktaalik → LUCA**.
5. Столкновение — конец игры; пробел/клик — заново.

## Чит-панель (только index-dev.html)

| Кнопка | Действие |
|---|---|
| GodMode | Неуязвимость |
| Пропустить загрузку | Мгновенно завершить 30-секундное ожидание |
| Рестарт игры | Сброс текущего забега |
| Скорость | Ускорение игры 0.5×–4× |

## Структура проекта

```
ChromeZavr/
├── loading-page.html      # PROD: экран загрузки + игра
├── index-dev.html         # DEV: то же + чит-панель
├── engine.js              # игровой движок (общий)
├── assets/epochs/         # файлы эпох (названия, палитры, враги)
├── docs/
│   ├── EPOCH_FILES.md     # формат файла эпохи
│   ├── IA_USERFLOW.md     # информационная архитектура и юзерфлоу
│   ├── CHANGELOG.md       # история изменений
│   ├── PROMPT_HISTORY.md  # история требований
│   ├── LOADING_PAGE.md    # документация страницы загрузки
│   └── Plot/              # сюжет: полная линия 20 эпох + 5 избранных
```

## Технологии
